## Descripción del Proyecto
Este programa realiza la conjugación automática de verbos regulares en español (terminaciones -ar, -er, -ir) en tiempo presente. El software implementa una lógica robusta para identificar la raíz del verbo, validar su terminación y generar las 6 formas personales correspondientes, utilizando estructuras de datos como listas y diccionarios para un procesamiento eficiente.
